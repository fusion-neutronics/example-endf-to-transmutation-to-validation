# NJOY reconstructs the resonances and Doppler broadens, which no library and
# no language can avoid, so a binary is still needed. njoy2016 is not on PyPI;
# this wheel puts an `njoy` in the venv's bin/. Use your own build instead with
# `--njoy`, which is also how you point at the IAEA-NDS fork that FENDL needs.
--extra-index-url https://shimwell.github.io/wheels
njoy2016

# yani reads the nuclear data and now makes it too: the ENDF conversion, the
# reaction topology and the isomeric branching are all functions on the wheel.
# Nothing here resolves against a sibling checkout, and there is no `endf`
# package pinned to a branch of a fork.
#
# The package used to be called yats, which is unusable as a PyPI name: it
# belongs to an unrelated Twitter scraper that installs happily and then has no
# convert_* functions, so the failure arrived as a baffling AttributeError.
# `yani` is free, and this line becomes a plain `yani` once the first wheel is
# published under it. Until then it installs from git.
# See fusion-neutronics/core#444.
yani @ git+https://github.com/fusion-neutronics/core.git#subdirectory=packages/yani
